# Durian Map デザイン規約

最終更新: 2026-09-14

UI を実装・変更する人は、コードを書く前に必ずこのファイルを読むこと。
色の具体値は **`docs/design-tokens.md` が正**（このファイルでは重複させない）。
ビジュアルの元ネタは `designs/durian-map-tropical.pen`（プレビュー: `designs/durian-map-tropical.png`）。

## 0. 大原則

1. **フラット。グラデーションは使わない。**
2. **タグ（チップ）を飾りで置かない。**
   `.pen` のカード・詳細には `自家焙煎` `個人経営` `Wi-Fi` が描かれているが、
   これらは Places API から取れない。推測で出すことになるので**実装しない**。
3. デザイン案（.pen）は「雰囲気の参照元」であって、1px 単位のコピー元ではない。
   案に描かれていても、下の禁止事項に当たるものは**実装しない**。

## 1. 禁止事項（明示的に却下されたもの）

### グラデーション禁止

- 背景・ボタン・ヘッダー・カード、どれもグラデーションにしない。**単色（ベタ塗り）で塗る。**
- `linear-gradient` / `radial-gradient` / `conic-gradient` を新規に書かない。
- .pen 案の「現在地の周辺で探す」CTA はマンゴーのグラデーションになっているが、
  **実装では `--dm-cta`（`#F6A21B`）のベタ塗りにする。**
- `docs/design-tokens.md` に書かれている `（グラデ上端 #FBBF3F）` という注記は**無効**。使わない。
- **既存の負債**: `frontend/src/app/globals.css` の `body` に radial-gradient 4 枚 +
  linear-gradient が残っている。`body::before` のドットテクスチャも同様。
  これは**削除して `--dm-surface`（`#FFF7E6`）のベタ塗りに置き換える**。

> 例外は「写真の上に文字を載せるための可読性オーバーレイ」のみ。
> その場合も黒の不透明度（`rgba(0,0,0,.35)` 程度）に留め、色付きグラデーションにはしない。

### 不用意なタグボタン禁止

タグ（`自家焙煎` `レコード` `個人経営` `Wi-Fi` のような小さなピル）は、次を**すべて**満たすときだけ置く。

- [ ] 実データに裏付けがある（API から取れている、またはユーザーが付けた）。ダミー・推測で出さない。
- [ ] ユーザーの判断を助ける情報である（「そのカフェを選ぶ／選ばない」に効く）。
- [ ] 1 カードにつき **最大 2 個**。余ったら出さない（「+3」のような省略表示もしない）。

そして **タグはボタンに見せない**。

- 押せないタグ → 枠線なし・影なし・ホバー効果なし。ただの色付き文字。
- 押せるタグ（フィルタ等）→ 押せるとわかる見た目にし、**必ず実際にフィルタとして機能させる**。
  「見た目だけのフィルタ」は作らない。
- 状態バッジ（`営業中` `準備中` `行きたい` `訪問済み`）はタグではない。**状態バッジは押せない**ので
  上記の「押せないタグ」のスタイルに従う。

### その他やらないこと

- 意味のない装飾（斜めの帯、ノイズテクスチャ、背景の光彩、パララックス）。
- 1 画面に主要 CTA を 2 つ以上置く。**最重要 CTA は 1 画面 1 つ**（`--dm-cta` はそれ専用）。
- 絵文字をアイコンの代わりに使う。アイコンは SVG で統一する。

## 2. タイポグラフィ

| 用途 | フォント | ウェイト |
|---|---|---|
| ロゴ、アイコン内の文字、英字見出し、**数値**（評価・距離・件数） | **Co Headline**（Dalton Maag） | Light / Regular / Bold |
| 日本語（本文・見出し・UI ラベル全般） | **M PLUS Rounded 1c** | 400 / 500 / 700 / 800 |

ルール:

- Co Headline は**欧文専用**。日本語が混ざる文字列では M PLUS Rounded 1c にフォールバックさせる。
  `font-family: var(--font-display), var(--font-sans), sans-serif;` の順で指定する。
- 「4.8」「(212)」「280m」「12件」のような**数値は Co Headline**。ここが揃うとブランドらしく見える。
- ロゴ・マップマーカー・アイコン画像・デザイン案（Pencil / Figma）で文字を含める場合も
  **Co Headline Bold** を指定する。
- Geist は使わない。

**現状**: 下記はすべて導入済み（`frontend/src/app/layout.tsx` / `globals.css`）。

- [x] `frontend/src/app/fonts/CoHeadline-{Light,Regular,Bold}.woff2` を配置
- [x] `next/font/local` で読み込み、CSS 変数 `--font-display` として公開
- [x] `--font-geist-sans` → `--font-sans` にリネーム、`Geist_Mono` を削除
- [x] `globals.css` の `@theme inline` に `--font-display` を追加

## 3. 色

**値は `docs/design-tokens.md` を参照。ここでは使い分けだけ定義する。**

- 面（背景・カード）: `--dm-surface`。**ベタ塗り**。
- 主要アクション（地図でみる、送信、アクティブタブ）: `--dm-primary`（濃緑）+ 白文字。
- 最重要 CTA（現在地の周辺で探す）: `--dm-cta`（マンゴー）**ベタ塗り** + `--durian-seed-900` の文字。
  1 画面 1 つ。
- 保存・行きたい: `--dm-accent`（ハイビスカス）。**面積を小さく**。
- 営業中: `--dm-success`、背景は `--durian-lime-100`。
- 位置情報・補助: `--dm-info`。
- 罫線: `--dm-border`。1px。
- Tailwind は任意値（`bg-[#1F6B3F]`）を新規に書かない。`bg-primary` などトークン由来の
  ユーティリティか、`var(--dm-*)` を使う。

コントラスト: 本文は 4.5:1 以上を守る。クリーム地に黄色系の文字は**禁止**。
淡色地（`-100` 系）に文字を載せるときは `--dm-success-text` / `--dm-accent-text` を使う
（`-500` 系をそのまま文字にすると 4.5:1 を割る）。検証済みの比は `docs/design-tokens.md` 参照。

## 4. 形・余白

| 要素 | 角丸 |
|---|---|
| カード、シート、モーダル | 16px |
| ボタン、入力欄 | 12px |
| タグ・状態バッジ | 999px（ピル） |
| サムネイル画像 | 12px |
| ヘッダー下端 | 24px（下 2 角のみ） |

- 余白は **4px グリッド**。よく使うのは 8 / 12 / 16 / 24。
- 画面の左右パディングは 16px。
- 影は 1 種類だけ: `0 2px 8px rgba(20, 83, 45, 0.08)`。重ねない。強い影を作らない。
- タップ領域は最低 **44×44px**（iOS HIG）。

## 4.5 画面の骨格（モバイル）

上から **ヘッダー → 地図 → ボトムシート → 下部タブバー**。

- **ヘッダー（濃緑・下端角丸 24px）に検索コントロールをすべて置く。**
  ブランド行 / 現在地 CTA / エリア入力 / エリアチップ。
  検索が済んだら CTA とチップを畳み、CTA は入力欄の左のアイコンボタンになる。
  **シートの中に検索フォームを置かないこと** — 結果カードが 1 枚も見えなくなる。
- **ボトムシートはリスト専用**（角丸 30px）。中身はハンドル → 見出し（タイトル + 件数ピル +
  並び替え）→ カードのみ。half は領域の 52%、full は 88%。
- **下部タブバーは「さがす / 保存」の 2 つ**。.pen 案には履歴・マイページもあるが、
  機能が無いので作らない（§1「押せるのに効かない UI は作らない」）。
  `env(safe-area-inset-bottom)` を必ず見込む。
- 並び替え（近い順）は**現在地が取れているときだけ出す**。距離が出せないと意味を持たないため。

## 5. コンポーネント規約

### カード（カフェ 1 件）

上から: サムネイル（左, 64×64, 角丸 12px）／ 店名（16px Bold）＋ 状態バッジ ／
評価・件数・距離（数値は Co Headline）／ タグ最大 2 個。
**カード全体がタップ領域**。カード内に別のボタンを置かない（保存は詳細画面で行う）。

### ボタン

- Primary: `--dm-primary` ベタ塗り / 白文字 / 角丸 12px / 高さ 48px。
- Secondary: `--dm-surface` 地 + `--dm-border` の 1px 枠 / `--dm-text` 文字。
- CTA: `--dm-cta` ベタ塗り。1 画面 1 つ。
- アイコン + ラベルの縦積みは、3 つ並ぶアクション行（地図でみる / 保存 / シェア）でのみ使う。

### 絞り込みチップ（検索結果）

`営業中` / `〜¥1,000` / `¥1,000〜2,000` / `¥2,000〜` の 4 つ。**4 つとも実際に絞り込む**
（`design.md` §1「押せるのに効かない UI は作らない」）。価格帯は Places の `priceLevel` を
3 段にまとめたもの。価格帯どうしは OR、営業中とは AND。

折り返すと 2 行になってリストの高さを食うので、**横スクロールの 1 行**にする。
0 件になったら専用の空状態（「条件に合うカフェがありません」）を出す。

### 保存した状態（行きたい / 訪問済み）

保存すると既定は「行きたい」。詳細画面のセグメントで「訪問済み」に切り替える。
**保存していないカフェに状態は無い**ので、セグメントは保存後だけ出す。
保存画面の上部はセグメンテッドコントロール（すべて | 行きたい | 訪問済み）+ 件数。

### 詳細の情報行

34px の角丸アイコン枠（`--dm-surface-sunken` 地 / `--dm-primary` のアイコン）＋
10px のラベル ＋ 13px の値 ＋ 右シェブロン（リンクのときだけ）。
住所 / 営業時間 / 電話 / ウェブサイトの順。**値が取れないフィールドは行ごと出さない。**

### 状態バッジ

`営業中` = `--durian-lime-100` 地 / **`--dm-success-text`** 文字（先頭にドット）。
`準備中` `行きたい` = `--tropic-hibiscus-100` 地 / **`--dm-accent-text`** 文字。
`訪問済み` = `--durian-lime-100` 地 / `--durian-green-700` 文字。
**枠線・影・ホバーなし。**

> 文字に `--dm-success`（`#2E8B57`）や `--dm-accent`（`#E2467C`）を使わないこと。
> 淡色地の上で 4.5:1 を満たさない（3.60 / 3.17）。`-500` 系は面・枠・アイコン専用。

### 空状態・エラー

- 検索 0 件、保存 0 件は必ず専用の表示を用意する（白紙にしない）。
- エラーは `--dm-error` のトーストで明示する。無言で失敗させない。

## 6. Web / iOS 共通の注意

- このデザイン規約は **Web と iOS（Capacitor）で共通**。プラットフォームごとに分岐させない。
  → 方針の詳細は `docs/platform-strategy.md`。
- セーフエリアを考慮する（`env(safe-area-inset-*)`）。特にヘッダーと下部タブバー・ボトムシート。
  `layout.tsx` に `viewportFit: 'cover'` を入れてあるので `env()` は実値が入る
  （Web では 0 になるだけなので、常に足しておいてよい）。
  実装例: ヘッダーは `h-[calc(5rem_+_env(safe-area-inset-top))] pt-[env(safe-area-inset-top)]`。
- iOS Safari のズームは無効化済み（`layout.tsx` の `maximumScale: 1`）。
  入力欄のフォントは **16px 以上**にする（未満だと iOS が自動ズームする）。
- ダークモードは**現時点で対応しない**。ライトのみ。中途半端に `dark:` を足さないこと。

## 7. 永続化とブラウザ API

実体が Web と iOS で変わるものは `frontend/src/lib/` を必ず通す。
**UI コンポーネントから直接呼ばないこと**（iOS で差し替えられなくなる）。

| やりたいこと | 使うもの | 直接呼んではいけないもの |
|---|---|---|
| 保存済みカフェの読み書き | `lib/storage.ts` | `localStorage` |
| 検索・写真 URL | `lib/api.ts` | `fetch` |
| 現在地 | `lib/geolocation.ts` | `navigator.geolocation` |
| 共有 | `lib/share.ts` | `navigator.share` / `clipboard` / `alert` |

→ `docs/platform-strategy.md`
